# University-Library-Management-System.-
Introduction to Software Engineering Assignment 1  
In this project we will deal with university library management system . In this project we will automate daily library task like borrowing books , manage inventry , daily records and making it efficent for others to use it .
Project Main Scope and Objectives :
1) Student , faculty and admin access levels.
2) Search, add , update and organize books according to auther,title etc.
3) Issue and returning date of book.
4) For how much time book can be borrowed and fine incase of late submission of books.
